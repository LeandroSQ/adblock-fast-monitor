luci-app-adblock-fast-monitor

LuCI dashboard for adblock-fast on OpenWrt 25.12. Latest version: @VERSION@. Source: github.com/LeandroSQ/adblock-fast-monitor.

Install from LuCI (once)

  1. System → Administration → Repository Public Keys: paste @BASE_URL@/keys/@KEY_NAME@ into the box and click Add key. LuCI saves it as /etc/apk/keys/@KEY_NAME@.
  2. System → Software → Configure apk: add this line to /etc/apk/repositories.d/customfeeds.list and click Save: 
    @BASE_URL@/apk/packages.adb
  3. Click Update lists…, type luci-app-adblock-fast-monitor in Filter and click Install…. Dependencies (adblock-fast, ucode modules) come from the official OpenWrt feeds.

The app is then under Services → Adblock Fast Monitor. Updates show up in System → Software → Updates after Update lists….

Or over SSH

uclient-fetch -O /etc/apk/keys/@KEY_NAME@ @BASE_URL@/keys/@KEY_NAME@
echo @BASE_URL@/apk/packages.adb >> /etc/apk/repositories.d/customfeeds.list
apk update && apk add luci-app-adblock-fast-monitor

Or without the feed

Add the key (step 1), download a package below and install it with System → Software → Upload Package…. Every package is signed, so no --allow-untrusted is needed; you will not get update notifications this way.

Signing key

    @FINGERPRINTS@

Check it with openssl pkey -pubin -in @KEY_NAME@ -outform DER | sha256sum. If apk update reports UNTRUSTED signature for this feed, the key was rotated: add the new key from the project README, then remove the old one. Keep the key across firmware upgrades: the package lists it for sysupgrade, or add /etc/apk/keys/@KEY_NAME@ under System → Backup / Flash Firmware → Configuration.
